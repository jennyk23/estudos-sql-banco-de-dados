# Estudos de SQL e Banco de Dados

Repositório destinado ao registro de atividades práticas e estudos relacionados a **SQL, bancos de dados relacionais e manipulação de dados**.

Os exercícios foram desenvolvidos principalmente em **Google Colab**, utilizando diferentes cenários para praticar criação de tabelas, consultas, relacionamentos e operações com dados.

## Conteúdos praticados

- SQL
- Banco de Dados Relacional
- Criação e manipulação de tabelas
- Consultas `SELECT`
- Filtros com `WHERE`
- Ordenação de resultados
- Funções de agregação
- Relacionamentos entre tabelas
- `JOIN`
- Inserção e atualização de dados
- Regras de negócio
- Procedures e Triggers
- Modelagem de diferentes cenários
